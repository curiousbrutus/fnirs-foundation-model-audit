# fNIRS Foundation Model Audit

Code, frozen evaluation protocol and result files for the paper:

> **The fNIRS Foundation Model Audit: Independent Evaluation of MtReNIRS and the Case of the
> Random Encoder** — Eyyüb Güven (2026, preprint)

**Headline result.** On a held-out dataset absent from its pretraining corpus, a frozen MtReNIRS
encoder reaches **0.469 ± 0.095** three-class accuracy (chance 0.333), but a **randomly
initialised encoder of the same architecture** reaches **0.448 ± 0.010** over ten seeds — a
+2.04 pp advantage that is **not statistically significant** (*p* = 0.19). The architecture does
outperform hand-crafted features (*p* = 0.014); that advantage disappears once short-separation
channels are regressed out, at a cost of ~4.5 pp.

## Layout

```
paper/                     LaTeX source, bibliography and compiled PDF
code/audit/                evaluation harness (preprocessing, embeddings, LOSO probes, statistics)
code/audit/legacy/         superseded v0/v1 scripts, kept for provenance only
code/detectability/        companion detectability calculator (synthetic-HRF power analysis)
data/                      derived, epoch-level data used in the paper (see Data below)
results/                   per-fold accuracies, paired tests, permutation nulls, run logs
figures/                   figures as published
```

## Reproducing the paper

```bash
python3 -m pip install -r requirements.txt

# The evaluation code needs MtReNIRS's alignment package for 10-05 projection:
git clone https://github.com/microsoft/MtReNIRS third_party/MtReNIRS

# Point these at your local copies (defaults shown):
export LUKE_BIDS_ROOT=data/bids/2021-fNIRS-Analysis-Methods-Passive-Auditory

# 1. Build the three preprocessing variants from the public BIDS dataset
python3 code/audit/prep_variants.py

# 2. (optional) inspect the 10-05 alignment of each variant
python3 code/audit/align_variants.py

# 3. Main audit: pretrained vs 10 random seeds vs classical, three variants
OMP_NUM_THREADS=1 python3 code/audit/run_audit3.py

# 4. Stacking ablation under the same protocol
OMP_NUM_THREADS=1 python3 code/audit/run_stacking_v2.py

# 5. Paired statistics and figures
OMP_NUM_THREADS=1 python3 code/audit/paired_test.py
```

Single-threaded BLAS (`OMP_NUM_THREADS=1`) is strongly recommended: the probe operates on small
matrices and multi-threaded BLAS thrashes, slowing runs by an order of magnitude.

Everything runs on CPU. The whole audit completes in well under an hour on a laptop.

## Data

**Auditory dataset (used in all reported results).** Luke, Larson, Shader, Innes-Brown, Van Yper,
Lee, Sowman & McAlpine (2021), *Analysis methods for measuring passive auditory fNIRS responses
generated by a block-design paradigm*, Neurophotonics 8(2):025008. Publicly available from its
original authors; re-use under its original licence with attribution.

`data/` contains **derived epoch-level arrays** produced from that dataset:

| file | contents |
|---|---|
| `luke_raw.npz` | 1,020 epochs × 66 channels × 100 samples (33 pairs, short channels included) |
| `luke_long.npz` | 25 long pairs only |
| `luke_wss.npz` | 25 long pairs after short-separation regression |
| `luke_aligned.npz` | channel positions in standard 10-05 |

Regenerate rather than trust: `code/audit/prep_variants.py` rebuilds all three variants from the
raw BIDS files.

**Pilot recordings (detectability figure only).** Two informal, self-collected trigger-free pilot
sessions were used solely to illustrate the detectability calculator. They are **not included** in
this repository: they were collected without a formal ethics protocol or research consent, and
they are reported in the paper only as aggregate statistics under neutral session codes
(Session A / Session B). Any participant identifiers were removed from the code before release.

**Pretraining corpus.** MtReNIRS weights are from
[microsoft/MtReNIRS](https://github.com/microsoft/MtReNIRS) (MIT licence). The twelve pretraining
datasets are listed in that repository; the evaluation dataset used here is not among them. NEMO
(Spapé et al.) *is* part of the pretraining corpus and is therefore not a clean test set.
